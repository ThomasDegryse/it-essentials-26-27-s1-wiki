# GTA VI – De wereld van Leonida

Grand Theft Auto VI is een openwereldgame van Rockstar Games.
Het verhaal speelt zich af in de fictieve Amerikaanse staat Leonida, geïnspireerd op Florida.
Een van de belangrijkste locaties is Vice City, een bruisende stad gebaseerd op Miami.
De hoofdpersonages zijn Jason Duval en Lucia Caminos.
Samen raken ze betrokken bij de criminele wereld van Leonida.
De spelwereld bestaat uit steden, stranden, eilanden en uitgestrekte natuurgebieden.
In deze wiki ontdek je de belangrijkste personages en locaties van GTA VI.
